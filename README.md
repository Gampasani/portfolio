# 🚀 Teja Gampasani – Personal Portfolio

Welcome to my personal portfolio website built with **React**, **TypeScript**, **SCSS**, and **MUI (Material-UI)**. This project showcases my expertise, project history, and contact form. It also supports dark and light themes, responsive design, and modern UI animations.

🔗 **Live Demo**: [gampasani.github.io/portfolio](https://gampasani.github.io/portfolio)

---

## ✨ Features

- 💡 Light & Dark mode toggle
- 📱 Fully responsive UI
- 🧑‍💻 Detailed expertise section (technologies, tools, soft skills)
- 🛠 Projects with images and descriptions
- 📅 Timeline (education & internship history)
- 📬 Contact form with **EmailJS** integration

---

## 🛠️ Technologies Used

- **React + TypeScript**
- **Sass (SCSS)**
- **Material UI**
- **EmailJS**
- **React Vertical Timeline**
- **GitHub Pages**
